# Workflow: Sync Documentation

Triggered only by an explicit request to sync/update documentation.

## Steps

1. **Confirm scope.** Which solution/project/folder's docs are being synced, or is it genuinely all of them? Don't assume "all" unless the user says so.
2. **Update documentation from the current codebase**: for each doc in scope, delegate to [documentation-writer](../agents/documentation-writer.md) to diff the existing doc against current code.
3. **Preserve manual documentation**: any clearly human-authored content (explicit "Notes"/manual sections, or content not previously generated by this workflow) must be kept verbatim.
4. **Remove outdated information**: stale facts that no longer match the code must be removed, not left contradicting reality.
5. **Keep all docs synchronized**: if a change in one doc has implications for another in scope (e.g. a solution overview and its dependency graph), update both consistently within the confirmed scope — don't let them drift apart.
6. **Report**: a changelog-style summary of what was added, updated, and removed, per doc.

## Output

- Updated documentation files, scoped to what was confirmed, with manual content preserved.
- A summary of the sync (added/updated/removed) for the user to review.
