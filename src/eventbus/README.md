# EventBus

* EventBus (contracts package — `IEventBus`, `IIntegrationEvent`, `BindingNameAttribute`)
* EventBus.MassTransit.RabbitMQ (MassTransit + RabbitMQ implementation of `IEventBus`, plus consumer/module helpers)

See `samples/EventBusSample` and `samples/EventBusConsumer` for runnable end-to-end examples (publisher + consumer,
consumer-only) referencing these packages.
